# Linux - Prácticas ASIR

Bienvenido a mi repositorio de prácticas de Linux.

## Objetivo

Este repositorio recoge todas las prácticas y ejercicios que voy realizando durante mis estudios del Ciclo Superior de Administración de Sistemas Informáticos en Red (ASIR).

Mi objetivo es documentar mi evolución en Linux, desde los comandos básicos hasta la administración de sistemas, automatización con Bash y servicios de red.

- Comandos básicos
