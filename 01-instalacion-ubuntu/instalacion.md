# Práctica 1 - Instalación de Ubuntu en VirtualBox

## Objetivo

Instalar Ubuntu en una máquina virtual utilizando VirtualBox.

## Material utilizado

- VirtualBox
- Ubuntu
- Windows 11

## Pasos realizados

1. Descarga de la ISO de Ubuntu.
2. Creación de la máquina virtual.
3. Configuración de la memoria RAM.
4. Configuración del disco virtual.
5. Instalación de Ubuntu.
6. Primer inicio del sistema.

## Resultado

La instalación se realizó correctamente y la máquina quedó preparada para comenzar las prácticas de Linux.

## Lo que aprendí

- Crear una máquina virtual.
- Instalar Ubuntu.
- Configurar los recursos básicos de la máquina virtual.
